# Taqwa Services Website

This repository contains the source code for **Taqwa Services** official website:
http://taqwa.services/

The website is built using **HTML, CSS, and JavaScript** and is designed to present professional services, manpower solutions, and company information in a clean, responsive, and user-friendly way.

---

## Project Overview

**Taqwa Services** is a professional services company providing maintenance, technical, and manpower solutions.  
This website serves as a digital presence to showcase services, contact details, and business information.

---

## Features

- Responsive design for desktop, tablet, and mobile
- Clean and modern UI
- Service sections (Maintenance, Technical, Manpower)
- Contact / Inquiry section
- Fast loading static website
- SEO-friendly structure
- Easy to customize

---

## Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & Layout  
- **JavaScript (Vanilla JS)** – Interactivity  

No frameworks or libraries required.
